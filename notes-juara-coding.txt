ALAMAK:
Project menggunakan layout Clean Architecture dengan pemanfaatan dependency injection (Wire) dan latar belakang token cleanup worker yang baik. Namun, terjadi kekurangan yang sangat krusial pada pemenuhan tugas Project 3: kode program hanya menyediakan fitur otentikasi (register, login, logout) serta model karyawan dasar. Modul penggajian (payroll), anggaran divisi (department budget), serta pengajuan cuti (leave request) sama sekali belum diimplementasikan di repositori ini. Akibatnya, fungsionalitas transaksi database (ACID), pessimistic locking, dan mitigasi kerentanan IDOR pada cuti tidak dapat dievaluasi sama sekali karena fitur tersebut tidak ada.
